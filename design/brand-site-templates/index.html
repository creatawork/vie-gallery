评审要点

  • 必备区块：每套均含 nav / hero / projects / contact（微信号展示 + 复制 + 留言表单）/ footer，转化路径完整（方案 T4 原则）。
  • 品牌定制：演示主色即"品牌定制"效果——同一主色在不同模板中的呈现强度不同（cta / edge 分级，方案 §6.2）。
  • 体验交互：复制微信、表单提交、T1 索引悬停、T4 场景环视均可交互；滚动脉冲遵循 prefers-reduced-motion。
  • 试用标识：T2 右下角"试用中 TRIAL"徽标为 PRD §5.1 的访客页标识槽位示意（仅示意，实际每套模板 footer 均预留）。
  • 字体：思源黑体/宋体经 Google Fonts 加载，离线时回退系统字体（雅黑/宋体/楷体）；工程实现按方案 §5.7 做子集化。
  • 性能预算：原型未做子集化与压缩，正式实现按 §5.7 验收（LCP ≤ 2.5s、模板资源 ≤ 120KB gzip）。
