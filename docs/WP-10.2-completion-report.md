## 🎨 动画系统架构

### 动画层级

```
照片切换动画系统
├── Lightbox 层 (2D 界面)
│   ├── 整体淡入淡出 (fade transition)
│   └── 图片切换动画 (image-fade transition)
│       ├── 进入: 300ms ease-out + scale(0.97→1)
│       └── 离开: 200ms ease-in + scale(1→1.03)
│
├── 3D 场景层
│   ├── 相机运动动画 (flyToPhotoAndFocus)
│   │   ├── 时长: 1400ms
│   │   ├── 曲线: Quartic Ease-Out
│   │   └── 特效: 视角轻微抬升
│   │
│   └── 照片淡入淡出 (PhotoFadePlugin)
│       ├── 首次加载: 交错淡入 (每张 +50ms)
│       ├── 聚焦动画: 300ms 透明度调整
│       └── 曲线: Cubic Ease-Out
│
└── 缓动函数库 (easing.ts)
    ├── Cubic Ease-Out
    ├── Quartic Ease-Out
    ├── Quintic Ease-In-Out
    ├── Exponential Ease-Out
    └── Back/Elastic Ease-Out
```

### 动画时序

```
用户点击照片
  ↓
[T+0ms] 触发 photo:click 事件
  ↓
[T+0ms] 开始相机飞行动画 (1400ms)
  ├── Quartic Ease-Out 曲线
  ├── 相机位置插值
  └── 相机目标插值
  ↓
[T+1400ms] 相机动画完成
  ↓
[T+1400ms] 打开 Lightbox
  ├── Lightbox 淡入 (300ms)
  └── 图片淡入 (300ms + scale)
  ↓
[T+1700ms] 完整动画链结束
```

## 🔧 缓动函数库

### 提供的缓动函数

```typescript
// Linear
linear(t) → t

// Cubic
easeInOutCubic(t) → smooth acceleration and deceleration
easeOutCubic(t) → fast start, smooth deceleration

// Quartic (推荐用于相机运动)
easeOutQuart(t) → stronger deceleration, cinematic feel

// Quintic
easeInOutQuint(t) → very smooth acceleration and deceleration

// Exponential
easeOutExpo(t) → fast start, extremely smooth deceleration

// Back (带回弹)
easeOutBack(t) → slight overshoot effect

// Elastic (弹性)
easeOutElastic(t) → spring-like bounce effect
```

### 预设配置

```typescript
easingPresets = {
  cameraFly: easeOutQuart,      // 相机运动
  photoFade: easeOutCubic,      // 照片淡入淡出
  uiElement: easeInOutCubic,    // UI 元素
  lighting: easeOutCubic        // 光照过渡
}
```
