```
├── WARM_PRESET (温暖)

│   ├── Fog: 金橙 + 中等 (0.00035)
│   └── Grading: 中暗角 + 电影感
│
├── DEEP_PRESET (深邃)
│   ├── Bloom: 强 (0.75/0.8/0.22)

│   └── Grading: 强暗角 + 戏剧性

└── MINIMAL_PRESET (极简)

    ├── Fog: 禁用
    └── Grading: 极轻暗角
```

### 协调流程

```
光照系统变化 (timeOfDay: sunset)
  ↓
config:change 事件触发
  ↓
BloomPlugin.handleLightingChange
  ↓
getAutoEffectPreset('sunset') → WARM_PRESET
  ↓
应用 Bloom 参数 (0.55/0.6/0.35)
应用 Grading 参数 (暗角/对比/饱和)
  ↓
FogPlugin.handleLightingChange
  ↓
应用 Fog 参数 (金橙 + 0.00035)
  ↓
视觉效果统一过渡
```

## 🔧 使用示例

### 配置方式

```typescript
// 1. 使用预设
engine.applyConfig({
  effects: {
    bloom: {
      enabled: true,
      preset: 'warm'  // fresh | warm | deep | minimal
    },
    fog: {
      enabled: true,
      preset: 'warm'
    }
  }
})

// 2. 自定义参数（覆盖预设）
engine.applyConfig({
  effects: {
    bloom: {
      enabled: true,
      preset: 'warm',
      strength: 0.6,  // 覆盖预设的 0.55
      radius: 0.7     // 覆盖预设的 0.6
    }
  }
})

// 3. 自动联动光照（推荐）
engine.applyConfig({
  lighting: {
    timeOfDay: 'sunset'  // 自动应用 Warm 预设
  },
  effects: {
    bloom: { enabled: true },
    fog: { enabled: true }
  }
})
```

## 🎬 视觉效果描述

### Fresh (清新)
- **Bloom**: 轻盈透亮，只有强光处略微发光
- **Fog**: 淡蓝色薄雾，营造清晨氛围
- **Grading**: 轻微暗角，高饱和度，清新明快
- **适合**: 婚礼照片、旅行风景、明亮人像

### Warm (温暖)
- **Bloom**: 柔和光晕，如黄昏余晖
- **Fog**: 金橙色雾气，温暖浪漫
- **Grading**: 中等暗角，高饱和，电影质感
- **适合**: 黄昏照片、温馨场景、情侣照片

### Deep (深邃)
- **Bloom**: 扩散光晕，梦幻氛围
- **Fog**: 深蓝色浓雾，神秘深沉
- **Grading**: 强烈暗角，高对比，戏剧性强
- **适合**: 夜景照片、城市灯光、艺术照片

### Minimal (极简)
- **Bloom**: 几乎不可见
- **Fog**: 完全禁用
- **Grading**: 极轻微暗角，接近原片
- **适合**: 需要突出照片本身内容的场景
