使用建议
=====================================

🎯 第一次使用：
  1. 阅读 QUICK-START.txt
  2. 执行 start-services.sh
  3. 运行 test-mcp-flow.sh
  4. 查看 TEST-SUMMARY.md

📚 深入了解：
  1. 阅读 TESTING-HOST.md
  2. 阅读 docs/testing-guide.md
  3. 参考 docs/mcp-test-guide.md

🧪 执行测试：
  1. 使用 TEST-CHECKLIST.txt 记录
  2. 运行 test-mcp-flow.sh
  3. 可选：test-browser-mcp.sh

🔧 问题排查：
  1. 查看 TESTING-HOST.md 故障排查章节
  2. 检查 Docker 日志
  3. 参考 docs/testing-guide.md
