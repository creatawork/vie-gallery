### ✅ T1.2: 时间段氛围模拟

**已实现功能**:
- ✅ 定义 4 种时间段氛围预设
  - **日出** (sunrise/dawn): 柔和橙色光 (#ffb380)，低强度 (0.4)，轻度雾效
  - **正午** (noon/day): 白色光 (#ffffff)，高强度 (1.0)，无雾效
  - **黄昏** (sunset/dusk): 金橙色光 (#ff9966)，中等强度 (0.8)，金色雾效，粒子密度 0.3
  - **夜晚** (night): 蓝紫色光 (#4466aa)，低强度 (0.3)，深蓝雾效，粒子密度 0.6
- ✅ 每种氛围包含环境光、主光源、辅助光源、雾效和粒子建议
- ✅ 提供配置项: `viewerConfig.lighting.timeOfDay`
- ✅ 支持自动选择（根据当前时间）
- ✅ 预设间平滑插值过渡

**文件**: `apps/gallery-viewer/src/presets/lightingPresets.ts`

**验收标准**: ✅ 4 种预设视觉效果明显，氛围感染力强

## 🎨 系统架构

### 光照系统组件

```
LightingPlugin (核心控制器)
├── 环境光 (AmbientLight)
├── 主方向光 (DirectionalLight) 
├── 辅助点光源 (PointLight)
├── 预设系统 (lightingPresets.ts)
│   ├── 4 种时间段预设
│   └── 预设插值过渡
└── 颜色分析 (colorAnalyzer.ts + worker)
    ├── K-means 聚类
    ├── HSL 色彩空间转换
    ├── 色温检测
    └── Web Worker 加速
```

### 数据流

```
用户点击照片
  ↓
App.vue 触发 photo:click 事件
  ↓
LightingPlugin.handlePhotoChange
  ↓
colorAnalyzer.extractDominantColor (Web Worker)
  ↓
创建照片适配的光照预设
  ↓
applyPreset (启动过渡动画)
  ↓
update() 循环插值光源参数 (2秒)
  ↓
光照平滑过渡完成
```

## 🔧 配置选项

### ViewerConfig 新增配置

```typescript
{
  lighting: {
    /** 时间段模式 */
    timeOfDay: 'auto' | 'sunrise' | 'noon' | 'sunset' | 'night',
    
    /** 是否根据照片主色调自动调整 */
    autoColorAdapt: boolean,  // 默认 true，低端设备自动禁用
    
    /** 颜色适应过渡时间（秒） */
    transitionDuration: number  // 默认 2.0
  }
}
```

### 使用示例

```typescript
// 使用自动时间段模式 + 照片颜色适应
engine.applyConfig({
  lighting: {
    timeOfDay: 'auto',
    autoColorAdapt: true,
    transitionDuration: 2.0
  }
})

// 固定使用日落氛围，不随照片变化
engine.applyConfig({
  lighting: {
    timeOfDay: 'sunset',
    autoColorAdapt: false
  }
})
```
