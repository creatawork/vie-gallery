### WP-10.1：动态光照系统优化

  - [ ] 色彩聚类（K-means 或简化算法）

  - **文件**：`apps/gallery-viewer/src/presets/lightingPresets.ts`（新建）

  - [ ] 增加细微的法线贴图或凹凸贴图效果
  - [ ] 确保照片在不同光照下都清晰可辨
  - **文件**：`apps/gallery-viewer/src/core/ViewerEngine.ts`（修改 Mesh 创建部分）
  - **验收标准**：照片在各种光照下不过曝、不过暗

- [ ] **T1.4：环境光与照片主色调的自动联动**
  - [ ] 在照片切换时触发色彩分析
  - [ ] 平滑过渡到新的环境光颜色（Tween 动画）
  - [ ] 提供开关选项：`viewerConfig.lighting.autoColorAdapt`
  - [ ] 过渡时间：1.5-2 秒
  - **文件**：`apps/gallery-viewer/src/core/ViewerEngine.ts`
  - **验收标准**：切换照片时环境光平滑变化，无突兀感

  - [ ] 色彩分析使用 Web Worker（避免阻塞主线程）
