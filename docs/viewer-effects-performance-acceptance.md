## 启动与预览

在上述工作目录按项目现有方式启动 API、Admin、Viewer。开发默认 Admin 使用 5173，Viewer 使用 5174。验收用独立端口 15173/15174 也有对应映射。

部署在不同来源时，Admin 配置 `VITE_VIEWER_ORIGIN`，Viewer 配置 `VITE_ADMIN_ORIGIN`，均填写完整来源，例如 `https://viewer.example.com`；协议、域名和端口必须完全一致。生产默认同源。预览只接受对应 iframe / 父窗口消息，不接受 `null` 来源。

新窗口预览读取服务端草稿；先保存后打开。内嵌预览应用未保存的有效配置，收到引擎完成回执后显示“已应用”和有效画质。错误可点击“重新应用”，握手超时可重试连接。

## 操作清单

| 项目 | 操作 | 预期结果 |
|---|---|---|
| 八种场景 | 在氛围中切换极简、森林、星空、海洋、日落、浪漫、冬日雪境、胶片展厅 | 背景、布局和效果有明显变化；旧场景的粒子颜色等可选参数不残留 |
| 布局 | 修改照片大小、间距；切换布局后修改对应半径、列数、高度、圈数 | 实际照片位置和大小改变；无重叠闪回，追加分页保留已有照片 |
| 粒子 | 分别选择六种类型，调整密度/速度/大小/颜色，密度设为 0 | 每个参数影响实际粒子；0 密度不显示粒子；速度 0 暂停运动 |
| 后处理 | 单独开启调色、暗角；关闭辉光再调整亮度/对比度/饱和度 | 调色和暗角独立生效；所有后处理关闭时仍正常显示照片 |
| 背景和雾 | 切纯色/渐变，修改主副色、角度及雾密度 | 背景随参数改变；不被光照时刻自动覆盖 |
| 运动 | 开关浮动、入场、布局过渡、巡航和开场飞行并调整速度/时间 | 开关与参数有效；拖动相机中止开场飞行；系统减少动态效果时暂停相应运动 |
| 保存 | 修改参数与画质，保存草稿，刷新配置页 | 全部字段保持；请求期间的新编辑仍显示未保存；旧音频和未知扩展字段继续保留 |
| 错误输入 | 颜色输入 `invalid`，数值输入超限或清空 | 显示字段错误；保存及自动保存被阻止；预览继续使用最后有效配置 |
| 恢复预设 | 修改效果后点击恢复当前预设 | 恢复效果和布局；质量上限、下载设置和扩展字段保留；已自定义标记清除 |
| 实时预览 | 连续修改参数和切场景 | 最后一次有效配置落到预览，显示应用回执；无需刷新 iframe |
| 发布与回滚 | 保存后同步；恢复历史版本为草稿，再同步 | 保存草稿不改访客配置；同步才改变访客效果；失败时线上版本保持 |
| 访问 | 密码相册解锁、会话过期后继续分页、重新解锁 | 解锁后读取当前配置；失效后清除照片与下载权限；旧请求不恢复权限 |
| 加载失败 | 使图片地址加载失败，然后恢复并重试 | 占位可见，重试可恢复照片；不会无限重试或重复建立同一纹理 |
| 模式切换 | 反复切换 2D/3D，再切场景和关闭页面 | 不出现旧引擎回写、持续增长的纹理或重复监听 |
| 降级 | 在较慢设备使用复杂场景，或令 WebGL 上下文丢失 | 自动减少显示开销；必要时切换经典画廊，照片可继续浏览 |
| 边界内容 | 空相册、一张竖图、长标题、空图片地址 | 有明确空状态；单图正常；标题和控件不溢出 |
| 布局适配 | 桌面、窄屏和键盘操作 | 控件有标签和焦点；内容可滚动，预览工具不溢出 |

## 资源预算与性能目标

质量选择为上限；自动模式桌面从中档、移动/低性能设备从低档开始。连续 3 个有效窗口低于 30 FPS 降一档，连续 8 个窗口达到 55 FPS 恢复一档，每次变化冷却 10 秒。空闲、隐藏、加载、转场和上下文丢失不参与判定。低档连续 5 个有效秒低于 20 FPS 切换经典画廊。用户保存的质量值保持不变。

| 有效质量 | DPR 上限 | 纹理最大边 | 纹理估算预算 | 并发 | 驻留数量 | 粒子上限 | 后处理缩放 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 低 | 1 | 512 | 32 MiB | 2 | 32 | 200 | 0.5 |
| 中 | 1.5 | 1024 | 64 MiB | 3 | 64 | 700 | 0.75 |
| 高 | 2 | 2048 | 128 MiB | 4 | 96 | 1600 | 1 |

纹理预算是估算 GPU 纹理占用，不包括下载缓冲区、原图解码内存和驱动开销。200/500 张相册的非驻留照片会显示占位，转动相机后按可见性补充纹理。

原设计性能目标保留，尚未执行最终测量：桌面 50 张、中档星空场景 FPS 中位数 ≥50、帧间隔 p95 ≤33ms；真实移动设备 50 张、低档森林场景 FPS 中位数 ≥30、p95 ≤50ms；200/500 张追加场景同步目标 <200ms。20 次场景和 10 次模式切换后的资源增长目标不超过 `max(10%, 2)`；同质量场景 CPU 渲染 p95 回归不超过 10%。移动视口模拟不等于真实移动设备验收。

需要记录时可在开发环境使用 `window.__VIE_VIEWER_DIAGNOSTICS__.snapshot()` 查看请求配置、有效画质、粒子数、纹理预算和渲染指标，`drainFrames()` 取出并清空有限帧记录。生产诊断默认关闭，显式 `VITE_VIEWER_DIAGNOSTICS=true` 才启用。不要以空闲降频期间的 FPS 作为性能结论。
