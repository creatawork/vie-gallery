## 1. 背景与目标

### 1.1 背景

VIE Gallery 已完成个人相册 V1 Ready 验收，核心链路（注册 → 建相册 → 上传整理 → 配置展示 → 发布 → 分享 → 访客访问）闭环。

v1.0 草案在评审中发现四个结构性问题：

1. **三产品一套餐**：个人存储分享、创作者品牌作品集、摄影师客户交付工具被塞进同一个 Pro 套餐，升级路径不成立；
2. **付费理由 = 容量**：相册数/照片数/存储量三把尺子并存，用户难以预判哪项先触顶，容量差异无法解释"为什么付费"；
3. **试用与意图错位**：注册即开始 14 天倒计时，大量用户在准备好作品前就耗尽试用期；
4. **对存量功能收费**：密码分享、过期链接在 V1 已面向全部用户上线，划入付费清单等于上线即降级。

同时确认的产品事实：2026-09-17~10-17 路线图（WP-10~17）不含任何套餐/计费承诺，本 PRD 为**新增产品层**；工程底座（租户配额、权限能力枚举、分享链接与短链、草稿/发布分离）可直接承载套餐模型，无需推倒。

### 1.2 目标

- 建立免费账号与品牌站订阅的双资产结构，免费层完整传递 3D 欣赏核心价值；
- 首个付费闭环锁定独立摄影师的**获客展示**：品牌站 → 精选项目 → 联系转化 → 询盘可量化；
- 试用机制与建站意图对齐，让用户先在真实获客中感受付费价值再决策；
- 为后续"客户交付工具链"（选片、交付状态、客户专属页）预留产品结构位，不在本期实现。

### 1.3 非目标

- 本 PRD 不涉及具体定价（金额、周期、促销策略）；
- 本 PRD 不涉及支付渠道接入方案；
- 本 PRD 不涉及品牌站模板的具体设计稿；
- 本期不实现自定义域名、客户交付工具链、多品牌站。

## 2. 分层原则

| 原则 | 说明 |
|---|---|
| P1：免费版不阉割核心体验 | 免费版 3D 欣赏体验完整、流畅、能打，承担"让人爱上产品"的任务，3D 效果不区分档位 |
| P2：付费差异落在站点资产 | 已暂停的历史方案：以持续在线的品牌站作为付费差异；当前不属于产品范围 |
| P3：免费版成本可控 | 客户端渲染下 CDN 成本极低，存储是唯一硬约束，设账号级上限 |
| P4：到期不制造"白做了"的体验 | 站点到期仅下线公开访问，编辑器与预览永久保留，照片与配置永不因订阅状态被惩罚 |
| P5：数据可携带是退出权 | 批量原图导出、配置导出对所有人免费，付费点不落在"拿回自己的照片" |
| P6：已上线能力不回收 | V1 已面向免费用户上线的功能（密码分享、过期链接、短链）永久保持免费 |

## 3. 资产与分层结构（双资产模型）

### 3.1 模型总览

```
账号（免费资产，注册即有，终身持有）
 ├── 相册 ×5 ─────── 3D/2D 欣赏、受控分享（完整 V1 能力）
 │                   支持：密码分享、过期链接、平台短链、访问计数、批量导出
 └── 品牌站（订阅资产，首版每账号 1 个）
      ├── 主页：Hero + 精选项目 + 关于我 + 联系转化（微信号展示/复制、站内表单）
      ├── 项目 = 引用相册打包（相册不搬家，一个项目 = 相册 + 站内包装）
      ├── 品牌定制：名称、Logo、主色；访客页去水印
      ├── 平台泛子域名（原方案，已随品牌站一并暂停）
      └── 获客看板：原品牌站方案，已暂停
```

**历史方案关键设计**：项目是相册的引用而非拷贝。同一相册可同时保持免费分享链接与被品牌站引用；该双资产订阅方案已暂停，不代表当前产品行为。

### 3.2 品牌站状态机

```
创建品牌站 ──→ TRIAL（14 天，全功能，公开可访问，带"试用中"标识）
                 ├─→ ACTIVE（付费订阅生效，标识去除）
                 └─→ EXPIRED（到期未升级）
                       └─→ 升级复活：配置、项目、域名原样恢复
EXPIRED 状态下编辑器与预览永久保留，公开访问下线
```

## 4. 权益分层对照

### 4.1 对照表（修订版）

| 维度 | 免费版（个人欣赏） | 专业版（品牌站订阅） | 相对 v1.0 的修正 |
|---|---|---|---|
| 3D/2D 展示 | 完整可用，场景/光影不打折 | 同 | 不变（P1） |
| 相册额度 | 5 册 / 单册 300 张 / 5GB 原图 | 同额度起步；订阅含账号存储扩容（建议 20GB，待评审） | 修正：不再用"3 册/200 张"制造升级门槛 |
| 密码保护 / 过期链接 | **保留免费** | 同 | **修正：移出付费清单**（P6，V1 存量能力） |
| 数据导出 | 批量原图导出、配置导出 | 同 | **修正：移出付费清单**（P5） |
| 分享链接 | 平台短链 + 访问计数 | 同，另加品牌站优雅路径 | 修正：短链等 V1 能力保持免费 |
| 站点/展示 | 保持相册分享与 Viewer | 品牌站已移除 | 当前无品牌站付费权益 |
| 域名 | — | 已暂停：平台泛子域名和自定义域名方案均不实施 | **历史提案；需随收费方案重新评估** |
| 访客数据 | 访问计数 | 来源、设备、停留时长、热门照片 + **联系点击数** | 复用路线图 WP-12/13 埋点规划 |
| 模板 | 相册氛围预设开放 | 品牌站模板已随功能移除 | 收费权益待重新评估 |
| 水印 | 分享页页脚"由 VIE Gallery 提供" | 品牌站访客页去除 | 不变 |
| 收录策略 | 个人分享页默认 noindex | 品牌站默认允许搜索引擎收录（获客需要） | 新增治理项 |

### 4.2 边界说明

- **免费触顶**：相册数、单册照片数、存储任一触顶即停止新增，已有内容只读可看可导出，引导开通品牌站（试用）而非硬性付费墙。
- **原付费差异方案已暂停**：站点资产、品牌定制、高级访客洞察和联系转化均不属于当前产品；其他付费权益待重新评估。
- **原首发站点参数已暂停**：单站项目数和订阅存储扩容不构成当前产品规格。

## 5. 品牌站试用规则

### 5.1 试用参数

| 规则项 | 值 | 说明 |
|---|---|---|
| 触发时机 | 已暂停 | 原方案以创建品牌站触发试用；收费方案重拟后再确定 |
| 试用时长 | 已暂停 | 原方案的 14 天时长不构成当前产品规则 |
| 试用资格 | 每账号一次 | 防拆号循环白嫖；客服通道可人工补开 |
| 功能范围 | 待重新评估 | 品牌站、泛子域名及其权益已移除；其他套餐权益待重新评估 |
| 对外公开 | 可公开发布 | 访客页带小字"试用中"标识（不可去除） |
| 核心体验 | 获客看板 | 试用期内持续呈现站点访问与联系点击数据，付费理由可视化 |
| 到期处理 | 站点 EXPIRED | 公开访问下线；编辑器、预览、配置、项目引用全部保留；升级一键复活 |

### 5.2 到期访客页（默认方案，待评审）

访客访问已到期站点时显示**极简暂停页**：站点名/摄影师名 + "站点已暂停，即将回归"系统提示，不展示照片、不提供联系方式与转化入口。备选方案：完全 404 下线（倒逼最强、对外最不专业）或保留联系卡（对用户最友好、削弱升级压力）——该项在 2026-09-28 评审中未获明确答复，按推荐默认收录，正式评审时定稿。

### 5.3 触达节奏

| 时间点 | 触达方式 | 内容要点 |
|---|---|---|
| 建站完成 | 站内引导 | 教学式引导：建站 → 上项目 → 配联系方式 → 发布 |
| 第 3 天 | 站内通知 | 首批获客数据回顾（"你的站点已被访问 N 次"） |
| 第 7 天 | 站内通知 + 邮件 | 试用过半，突出联系点击与剩余天数 |
| 第 12 天 | 站内通知 + 邮件 | 试用即将结束，说明到期后配置保留、一键复活规则 |
| 第 14 天 | 站内通知 + 邮件 | 试用到期，提供升级入口与暂停页说明 |
| 第 90 天未登录（账号级） | 邮件 | 沉睡提醒（见 §6 数据生命周期） |

邮件触达复用现有 EmailPort；埋点复用 WP-12 规划的分享统计（`track-event`）与 WP-13 的访客转化入口。

## 6. 账号数据生命周期（治理，非付费墙）

| 阶段 | 规则 |
|---|---|
| 正常期 | 5GB 原图额度按账号计算；额度只计原图，派生图（缩略图/Web 图/3D 纹理）不计入用户感知额度 |
| 触顶 | 停止新增，存量只读可看可导出；引导开通品牌站试用或等待清理空间 |
| 沉睡 | 90 天未登录 → 邮件提醒，预告清理时间与导出方式 |
| 清理 | 提醒后 30 天 → 按"原图 → 派生图 → 相册配置"顺序分步清理，每步均提前通知 |
| 退出权 | 任何状态下可自助批量导出原图与配置，不设付费墙（P5） |

**与 v1.0 的差异**：v1.0 的"超出容量只读 + 升级恢复可写"双轨状态机不再需要——存储配额挂在账号上全程一致；订阅状态只影响站点资产（§3），照片永不因订阅被惩罚（P4）。

## 7. 成本模型

### 7.1 渲染路线（维持 v1.0 结论）

客户端渲染（Three.js / WebGL），无 GPU 线性增长风险。单次完整浏览约 19 MB（场景包 15 MB + 照片 4 MB），按 ~0.10 元/GB 出口单价约 **0.002 元/次**，规模测算表沿用 v1.0（1 千用户 ~8 元/月 至 10 万用户 ~690 元/月）。

### 7.2 修订点

| 修订项 | 内容 |
|---|---|
| 存储按 3 倍系数规划 | 每张原图派生缩略图/Web 图/3D 纹理，实际占用约为原图 2–3 倍；用户感知配额只计原图，容量规划按 ×3 备货 |
| 站点基建成本 | 原品牌站方案的泛子域名、证书与站点限流成本假设已暂停，不构成当前上线依赖 |
| 自定义域名的隐性成本 | ICP 备案、DNS 配置支持、证书与滥用治理，作为 P2 加购项单独评估，不进入首发 |
| 冷数据 | 免费相册 30 天无访问自动降冷（沿用 v1.0） |
| 异常防护 | 单用户异常流量监控、分享 Token 限流（与 WP-16 安全加固合并实施） |

## 8. 指标与验证

### 8.1 指标体系

| 侧 | 指标 | 说明 |
|---|---|---|
| 付费侧（北极星） | 试用 → 付费转化率 | 目标值随定价文档确定 |
| 付费侧 | 订阅续费率 | 获客展示是否持续创造价值的核心证明 |
| 付费侧 | 品牌站联系点击率 | 给摄影师的价值证明，也是平台留存论据 |
| 免费侧 | 分享链接 → 注册转化率 | 依托 WP-13"创建我的相册"访客入口 |
| 成本侧 | 单账号存储均值、CDN 单位成本 | 对照 §7 模型告警 |

### 8.2 上线前 P0 验证

完整支付链路开发前，先做**人工陪跑试点**：3–5 名真实摄影师，用真实项目建站、配置联系转化、投放真实渠道，统计真实联系点击，并要求真实付款意愿表达（非问卷）。

- 原验证假设：摄影师愿意为持续在线的获客站点付费；品牌站移除后该假设暂停，不作为当前验收项；
- 证伪条件：试点期无人产生询盘或续费意愿 → 优先调整权益结构（如转向按项目付费发布），而非按原计划上线。

## 9. 验收标准

### 9.1 功能验收

- [ ] 免费版完整创建 3D 相册并流畅浏览；密码分享、过期链接、平台短链、批量原图与配置导出全部免费可用
- [ ] 免费额度触顶（任一维度）即停止新增并展示清晰引导，存量只读可导出
- [ ] 收费分层方案重拟后，另行确定试用、到期处理与用户触达验收项
- [ ] 账号治理：沉睡提醒、分步清理通知、批量导出全流程可用

### 9.2 非功能验收

- [ ] 免费版 3D 浏览在移动端低端设备可回退 2D，不阻塞
- [ ] CDN 缓存命中率达标，单次浏览成本符合 §7 估算
- [ ] 存储按 ×3 系数监控告警
- [ ] 个人分享页 noindex、品牌站收录策略按 §4 生效
