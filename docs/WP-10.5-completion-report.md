- 固定宽高比 (4:3)

**优化方案 A: Masonry 瀑布流布局**

```typescript
// 使用 CSS Grid + Masonry (实验性)
.editorial-photo-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
  grid-template-rows: masonry; /* 实验性特性 */
  gap: 20px;
}

// 或使用 JavaScript 瀑布流库
import Masonry from 'masonry-layout'

const grid = new Masonry('.editorial-photo-grid', {
  itemSelector: '.editorial-photo-card',
  columnWidth: 280,
  gutter: 20,
  fitWidth: true
})
```

**优化方案 B: 智能宽高比布局**

```typescript
// 根据照片真实宽高比动态调整
interface PhotoCard {
  photo: Photo
  aspectRatio: number // width / height
  gridSpan: number    // 占据的列数
}

function calculateLayout(photos: Photo[]): PhotoCard[] {
  return photos.map(photo => {
    const aspectRatio = photo.width / photo.height
    
    // 宽照片占 2 列
    const gridSpan = aspectRatio > 1.5 ? 2 : 1
    
    return { photo, aspectRatio, gridSpan }
  })
}
```

```css
.editorial-photo-card.wide {
  grid-column: span 2;
}

.editorial-photo-card.tall {
  grid-row: span 2;
}
```

**优化方案 C: 交错布局 (Staggered Grid)**

```css
.editorial-photo-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
  grid-auto-flow: dense; /* 自动填充空隙 */
  gap: 20px;
}

/* 每 3 张照片有 1 张突出 */
.editorial-photo-card:nth-child(3n + 1) {
  grid-column: span 2;
  grid-row: span 2;
}
```

```typescript
// 使用 ClickRipplePlugin 的效果
function handleCardClick(event: MouseEvent, index: number) {
  const card = event.currentTarget as HTMLElement
  const ripple = document.createElement('span')
  ripple.className = 'card-ripple'
  
  const rect = card.getBoundingClientRect()
  const x = event.clientX - rect.left
  const y = event.clientY - rect.top
  
  ripple.style.left = `${x}px`
  ripple.style.top = `${y}px`
  
  card.appendChild(ripple)
  
  setTimeout(() => ripple.remove(), 600)
  openLightbox(index)
}
```

```typescript
// 按年份/月份分组
function groupByDate(photos: Photo[]): Map<string, Photo[]> {
  const groups = new Map()
  photos.forEach(photo => {
    const key = new Date(photo.createdAt).getFullYear()
    if (!groups.has(key)) groups.set(key, [])
    groups.get(key).push(photo)
  })
  return groups
}
```

## 📊 2D vs 3D 模式对比

| 特性 | 3D 模式 | 2D 模式 |
|------|---------|---------|
| **视觉风格** | 沉浸式、空间感 | 编辑风格、杂志感 |
| **交互方式** | 相机飞行、旋转 | 滚动、点击 |
| **性能开销** | 中等 (WebGL) | 极低 (CSS) |
| **适合场景** | 展示、探索 | 浏览、选择 |
| **照片密度** | 低 (一次看几张) | 高 (一次看数十张) |
| **粒子/光照** | ✅ 支持 | ❌ 不适用 |
| **滤镜效果** | 有限 | ✅ 丰富 |
| **排序/筛选** | 不适用 | ✅ 支持 |
