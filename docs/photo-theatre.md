# 照片编排

公开相册的 3D 观看页底部提供“照片编排”。可选浮游照片云、轨道环廊、折页长廊、流动照片带、层叠相册、错落展墙，以及双联、三联、扇形组照、主图与碎片。照片保留原比例，按创作者既有排序组成批次；不足四张时采用单张或联画构图。照片尺寸较大时按现有纹理预算缩小批次，换组按实际批次大小前进，保证所有照片仍可浏览。

“播放编排”由访客主动启动一次 31 秒演出：照片云 → 环廊 → 折页 → 三联 → 单张 → 照片云。支持暂停、继续及结束后的重播。暂停同时冻结照片移动和进度；切换排列或换组会接管演出。切换浏览器标签页时不补跑隐藏期间的动画。

左右拖动、滚轮或方向键可浏览其他照片组。点击照片或使用“查看当前主图”进入聚焦和大图；关闭大图还原先前的排列和照片组。层叠相册可通过悬停展开为扇形。照片云保留轻微漂浮和鼠标视差，系统开启减少动态效果时关闭这些动作及自动播放。

编排属于访客临时观看状态。打开相册仍采用已发布配置；退出编排还原原机位和布局。它不写入创作者配置，不修改分享权限，不更换照片对象或重复构建照片纹理。追加照片后更新当前批次；切到 2D、修改布局、WebGL 丢失或页面销毁时释放编排状态。

实现位于 gallery-viewer 的 photoTheatre 构图函数和 PhotoTheatrePlugin，复用引擎的活动帧时钟。位置、尺寸、四元数旋转一同插值，不同目标构图采用不同的路径和启动顺序。PhotoTheatre 与 Layout 通过 theatre:active 交接照片变换的所有权，PhotoFade 继续负责材质透明度。宽高按相机视野和控件安全区域计算。

验证：仓库根目录运行 `npm run test:viewer:unit`；gallery-viewer 运行 `npm run verify` 和 `npx playwright test photo-theatre.spec.ts`。浏览器测试使用本地合成照片，覆盖十种形态、完整演出、手机及减少动态效果、暂停恢复、聚焦返回、资源身份和配置不变。

旋转插值和视野计算参考 [Three.js Quaternion](https://threejs.org/docs/pages/Quaternion.html) 与 [PerspectiveCamera](https://threejs.org/docs/pages/PerspectiveCamera.html)。
