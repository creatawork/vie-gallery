# 摄影空间 · 2026-10-14

用户授权自主重做，保留已认可的深靛、雾蓝、银白和暖光配色。目标是作品主导、有明确纵深的动态摄影展，而非远距离观看一团小照片。本轮采用直接实现并在浏览器验证的方式。

## 方向与验收

- Experience：首屏中央是一张可读的大幅完整作品，侧翼照片沿真实三维路径延伸。标题与控件退居画面边缘。
- 螺旋为向远处盘旋的照片流；环幕为展开的弧形放映幕；波浪为有起伏的横向摄影长卷。三者共用焦点和惯性，不重置当前照片。
- 拖动、滚轮、左右键、前后按钮控制同一连续进度。自动漫游逐幅停留；悬停放缓；点击看大图。暂停和减少动态偏好必须生效。
- 手机优先保证当前作品足够大，不为塞下全部照片而把画面缩成缩略图。完整集合仍可循序浏览和平面查看。
- 保留图片原始比例、共享配置、发布流程、访问控制、资源预算、无 WebGL 降级。

## 实施

1. 为焦点导航、照片序号和减少动态行为增加浏览器验收。
2. 增加仅服务精选布局的空间插件；由它统一拥有镜头和照片编排，旧布局保留原控制器。
3. 精选照片清晰呈色，装裱受光；空间变形采用时间阻尼，边缘循环淡出，避免穿帮。
4. 调整展示标题、当前照片信息、导航和移动端排版；维护产品记录。
5. 类型检查、现有单测、真实浏览器桌面/手机/降级验证，截图和独立审阅。
