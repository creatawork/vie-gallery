# Admin 登录页全屏沉浸视觉重做

日期：2026-09-08
范围：`apps/gallery-admin` 未登录态 UI（主要是 `OverviewView.vue`）
不改：鉴权 API、会话逻辑、字段与校验规则

## 目标

把当前居中 `auth-card` 登录态，改成**全屏沉浸**布局，气质清新，体现 VIE Gallery 画廊/空间展陈产品感。

## 布局

1. **全屏背景**：浅绿清新的画廊空间感（CSS 渐变 + 轻量光影/虚化展板装饰），不做真 3D / WebGL。
2. **表单浮层**：右侧半透明磨砂卡片（`backdrop-filter`），承载登录/注册。
3. **顶栏**：未登录时尽量弱化工作区导航噪音；优先让登录层盖满可视区，避免大改 `App.vue`。

## 表单（保持现有能力）

- Tab：账号登录 / 注册账户
- 登录：邮箱、密码
- 注册：显示名、邮箱、密码
- 提交文案与错误提示沿用现有逻辑
- **不做**：第三方登录、忘记密码、记住我

## 视觉

- 主色：现有翠绿系（`#10b981` / `#059669`）
- 卡片：磨砂玻璃、圆角、轻阴影
- 空气感：留白充足；窄屏下卡片改为近全宽居中

## 验收

- 未登录打开 Admin 首页即为全屏沉浸登录
- 登录/注册切换与提交行为与现网一致
- 登录成功后仍进入现有工作台
- 提供桌面端截图（必要时补窄屏）

## 非目标

- 不拆独立 `/login` 路由（除非实现时发现必须拆）
- 不改 Viewer / API
